## Findings

**P1. A seat can forward evidence to an excluded fallback candidate.** `evidence.js:36,92` evaluates the seat's preferred adapter kind. `team.js:86–92` builds seats with candidate lists, and `router.js:95` passes the same task and context to each candidate. A synthetic real `Seat` with a Claude Code candidate that returned an infrastructure failure and an Anthropic API fallback delivered a Claude-subscription-only passage to the API stub. Form the run-wide intersection over the full candidate set, including fallback and retry recipients. Reject unknown destinations. Check the actual candidate at dispatch as a second guard, including any derived task material from earlier calls.

**P1. The origin check does not constrain the transport.** `client.js:43,125–149` validates the URL and uses ambient global fetch. On Node 24.12.0, two local HTTP listeners and a child process with `NODE_USE_ENV_PROXY=1`, `HTTP_PROXY` set to the proxy listener and empty `NO_PROXY` reproduced a CONNECT tunnel. The proxy saw the synthetic bearer in the HTTP request, the target saw zero requests, and `collections()` succeeded with the proxy's response. Use a direct, explicitly controlled transport for the KB client or reject proxy configurations before dispatch. Keep redirect refusal, caps and timeouts. Verify that the proxy receives zero credential-bearing bytes with the production client path.

**P1. Abstention still sends passages.** `evidence.js:36–79,92–105` uses the evidence level only when the rendered passage list is empty. K6 legitimately returns keyword hits alongside `evidence: none` below its threshold (`knowledge/src/shingon_knowledge/service.py:346–350`). A synthetic valid-policy hit with level `none` was rendered with its excerpt and citation. Suppress the passages and issue the contract's no-support wording, alongside any applicable generic withheld notice. Add a nonempty `none` case to the existing empty-result test.

**P2. The advertised character limit measures excerpts only.** `evidence.js:58–61,105–111` leaves citation identifiers, locators, markers and notices outside the limit. A hit with a 13,000-character document ID and a short excerpt rendered 13,352 characters under the 12,000-character default. Cap the complete rendered block and validate the configuration limits. Preserve whole citations and passage boundaries when dropping items.

## Interface decisions

- **Call entry point.** Lazy assembly at `callAgent` and passing a block through the existing `callRole` context are suitable once candidate routing is covered. A phase-level freshness check leaves a gap between calls. Use per-call checks before dispatch. The same check must cover retries or fallback attempts that carry evidence-derived material.
- **Persistence and Resume.** Use a separate process-local field on `ctx` for passages and the client. The proposed `ctx.state.evidence` is serialized by `RunLog.saveState` at `runlog.js:46–50`. A direct control saved an evidence selection and found its synthetic excerpt in state.json. Persist only the provenance needed to enforce later dispatch, such as whether evidence was sent, the approved candidate scope, origin and revision. Resume rebuilds the team and restores plans and commits. Before it can send an evidence-assisted artifact, verify that the persisted scope and revision still permit that call.
- **After freshness loss.** Before any evidence is sent, dropping it and continuing is sufficient. Once an agent has consumed it, dropping the context block still leaves evidence-derived plans, notes and diffs in later tasks. Stop before forwarding those artifacts if the revision or recipients cannot be verified. Refetch alone cannot validate older derived text. Define the resumable stop and fresh-run behavior in the integration design.
- **Credential.** Reserve the fixed `CONDUCTOR_KB_TOKEN` for the trusted KB client and worker. Adding it to `SCRUB_ENV` alone is insufficient. A synthetic control found a lowercase Windows alias survives `childEnv`, and `allow` can override the scrub. The local adapter permits custom `envKey`, and `wake.js:107` explicitly picks configured variables. Make this key unallowable for downstream children, case-insensitively on Windows, and reject it as a provider or wake credential. Cover Git, test commands and model/wake child boundaries. Preserve the trusted service-to-worker handoff where needed.
- **Configuration and ownership.** Accept the off-by-default option for the ordinary Conductor run entry points, with bounded values and a validated origin. Reject enabled KB configuration at factory and council entry points for this slice. Keep service forwarding in Codex's later slice and UI display in Claude's later slice. Operator events carry structured metadata and withheld reports. The prompt gets only the allowed block or fixed notice. Any later PR touching protected paths follows the existing Malcolm merge gate.
