# Task 9: File uploads

This task delivers spec §5's "file uploads to storage". Receipts are photographed on phones (§2.3), so HEIC must work.

Files live on a private volume under random keys, never under the user's file name, and are served only through an authorised route. The type is decided by **sniffing the bytes**, not by trusting the name or the browser. Downloads can never render as a web page in the app's origin (Review Focus 3).

**Files:**
- Create: `apps/server/src/db/schema/files.ts`, `apps/server/src/files/{storage,sniff,repo,routes}.ts`
- Create: `apps/server/test/fixtures/files/{tiny.jpg,tiny.png,tiny.webp,tiny.heic,tiny.pdf,evil.svg,evil.html}`. These are generated by `apps/server/test/fixtures/make-fixtures.ts`, which writes the minimal valid headers listed in Step 3. They are committed.
- Create: `apps/server/test/crossing/resources/files.ts`
- Modify: `apps/server/src/app.ts`, `apps/server/test/crossing/{cases.ts,resources/index.ts}`
- Test: `apps/server/test/sniff.test.ts`, `apps/server/test/storage.test.ts`, `apps/server/test/files-routes.test.ts`, `apps/server/test/sweep.test.ts`

**Interfaces:**
- Consumes: `defineRoute`, `visibleTo`/`canSee`/`canEdit` (Task 4), `audit` (Task 5), `Config.uploadDir` and `uploadMaxBytes` (Task 2), the crossing harness (Task 8).
- Produces:
  - `Storage`, `LocalDiskStorage`, `sniffType`, `AllowedType` (index).
  - `FileView = { id, name, contentType, size, createdAt, ownerId }` in `@hf/shared`.
  - `apps/server/src/files/repo.ts`:
    - `getVisibleFile(db, actor, id): Promise<FileRow | null>`
    - `attachFile(tx, actor, fileId, parent: { type: string; id: string }): Promise<void>`: the actor must be able to edit the file (it must be theirs); otherwise `notFound()`.
    - `sweepOrphans(db, storage, olderThan: Date): Promise<number>`: deletes unattached files older than the date. `buildApp` runs it every 6 hours with `now - 24h`, outside `test` mode, and stops it on `onClose`. It deletes the storage object first and the row second, one file at a time, so a crash part-way leaves at worst a row whose object is gone (the next sweep removes it) and never an object no row points to. `sweep.test.ts` below pins it; it is the one destructive background job in this task.
  - Routes:
    - `POST /api/files` [`files:upload`]: multipart with one field, `file` → 201 `{ file: FileView }`.
    - `GET /api/files/:id` [`files:read`]: metadata.
    - `GET /api/files/:id/content` [`files:read`]: the bytes.
    - `DELETE /api/files/:id` [`files:upload`]: owner or admin only → 204.
  - Rules:
    - an empty file → 400 `That file is empty.`;
    - over `uploadMaxBytes` → 413 `That file is too large. The limit is 15 MB.` The limit text comes from `formatLimit(bytes: number): string` in `@hf/shared` (whole megabytes, `Math.round(bytes / 1048576)`, then the text ` MB`), which the web dropzone reuses (Task 13);
    - an unknown type → 400 `That kind of file isn't accepted. Use a photo (JPEG, PNG, WebP, HEIC) or a PDF.`
  - Download headers, always:
    - `X-Content-Type-Options: nosniff`
    - `Content-Security-Policy: default-src 'none'; sandbox`
    - `Cache-Control: private, no-store`
    - `Content-Type` = the sniffed type
    - `Content-Disposition: inline` for `image/jpeg|png|webp`; otherwise `attachment` (HEIC and PDF). The filename is RFC 5987-encoded: `filename*=UTF-8''<pct-encoded>`.

Table `files`:
- `id uuid pk`, `owner_id uuid not null references users(id)`, `team_id uuid null`;
- `storage_key text not null unique`, `original_name text not null` (≤ 200 chars, path separators stripped);
- `content_type text not null`, `size int not null`, `sha256 text not null`;
- `attached_type text`, `attached_id uuid`, `created_at`.
- `team_id` is the owner's team **at upload time**. Visibility uses it, so moving a person to a new team does not drag their old files along. That matches how expense records should behave.

```ts
import { test, expect } from 'vitest';
import { readFileSync } from 'node:fs';
import { sniffType } from '../src/files/sniff.js';

const f = (n: string) => readFileSync(new URL(`./fixtures/files/${n}`, import.meta.url));

  expect(sniffType(f('tiny.png'))).toBe('image/png');
  expect(sniffType(f('tiny.webp'))).toBe('image/webp');

  expect(sniffType(f('evil.svg'))).toBeNull();
  expect(sniffType(f('evil.html'))).toBeNull();
  expect(sniffType(Buffer.alloc(0))).toBeNull();
  expect(sniffType(Buffer.from('GIF89a'))).toBeNull();
});
```

```ts
import { test, expect } from 'vitest';
import { mkdtempSync, readdirSync } from 'node:fs';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { Readable } from 'node:stream';
import { text } from 'node:stream/consumers';
import { LocalDiskStorage } from '../src/files/storage.js';

test('put/get/delete round trip with size and hash; keys are sharded; no temp files left', async () => {
  const root = mkdtempSync(path.join(tmpdir(), 'st-'));
  const s = new LocalDiskStorage(root);
  const r = await s.put('ab12cd', Readable.from(['hello ', 'world']));
  expect(r).toEqual({ size: 11, sha256: 'b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9' });
  expect(await text(s.get('ab12cd'))).toBe('hello world');
  expect(readdirSync(path.join(root, 'ab'))).toEqual(['ab12cd']);
  await s.delete('ab12cd');
  expect(readdirSync(path.join(root, 'ab'))).toEqual([]);
  await expect(s.check()).resolves.toBeUndefined();
  expect(() => s.get('../etc/passwd')).toThrow(/invalid storage key/);
});
```

```ts
beforeAll(async () => {
  t = await createTestApp({ uploadMaxBytes: 1024 });
  const N = await makeTeam(t.db, 'N'), S = await makeTeam(t.db, 'S');
  alice = await makeUser(t.db, { role: 'member', teamId: N.id });
  carol = await makeUser(t.db, { role: 'member', teamId: S.id });

function upload(cookie: string, name: string, body: Buffer) {
  const boundary = 'hfboundary';
  const payload = Buffer.concat([
    Buffer.from(`--${boundary}\r\nContent-Disposition: form-data; name="file"; filename="${name}"\r\nContent-Type: image/jpeg\r\n\r\n`),
    body, Buffer.from(`\r\n--${boundary}--\r\n`)]);
  return t.app.inject({ method: 'POST', url: '/api/files', payload,
    headers: { cookie, origin: 'http://hf.test', 'content-type': `multipart/form-data; boundary=${boundary}` } });
}

test('a phone photo uploads and downloads with safe headers', async () => {
  const r = await upload(auth.cookie, 'IMG_0001.HEIC', fx('tiny.heic'));
  expect(r.statusCode).toBe(201);
  const file = r.json().file;
  expect(file).toMatchObject({ name: 'IMG_0001.HEIC', contentType: 'image/heic', size: fx('tiny.heic').length });
  const d = await t.app.inject({ method: 'GET', url: `/api/files/${file.id}/content`, headers: { cookie: auth.cookie } });
  expect(d.statusCode).toBe(200);
  expect(d.headers['x-content-type-options']).toBe('nosniff');
  expect(d.headers['content-security-policy']).toBe("default-src 'none'; sandbox");
  expect(d.headers['content-disposition']).toBe("attachment; filename*=UTF-8''IMG_0001.HEIC");
  expect(d.rawPayload.equals(fx('tiny.heic'))).toBe(true);
});

test('a disguised SVG/HTML, an empty file and an oversized file are refused', async () => {
  for (const n of ['evil.svg', 'evil.html']) {
    const r = await upload(auth.cookie, 'receipt.jpg', fx(n));
    expect(r.statusCode).toBe(400);
    expect(r.json().error).toBe("That kind of file isn't accepted. Use a photo (JPEG, PNG, WebP, HEIC) or a PDF.");
  }
  expect((await upload(auth.cookie, 'empty.jpg', Buffer.alloc(0))).json().error).toBe('That file is empty.');
  const big = Buffer.concat([fx('tiny.jpg'), Buffer.alloc(1025 - fx('tiny.jpg').length)]);
  const r = await upload(auth.cookie, 'big.jpg', big);
  expect(r.statusCode).toBe(413);
  expect(readdirCount(t.storageDir)).toBe(1); // only the HEIC from the first test; nothing partial left behind
});

test('another team\'s member gets 404 for the file and its content', async () => {
  const r = await upload(auth.cookie, 'a.png', fx('tiny.png'));
  const id = r.json().file.id;
  const c = await signInAs(t, carol);
  for (const url of [`/api/files/${id}`, `/api/files/${id}/content`])
    expect((await t.app.inject({ method: 'GET', url, headers: { cookie: c.cookie } })).statusCode).toBe(404);

const readdirCount = (dir: string) => countFiles(dir); // stored objects, ignoring in-flight .tmp files
function countFiles(d: string): number { return readdirSync(d).reduce((n, e) => { const p = path.join(d, e); return n + (statSync(p).isDirectory() ? countFiles(p) : e.endsWith('.tmp') ? 0 : 1); }, 0); }
```

`apps/server/test/sweep.test.ts`:

```ts
import { test, expect } from 'vitest';
import { mkdtempSync } from 'node:fs';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { Readable } from 'node:stream';
import { text } from 'node:stream/consumers';
import { createTestDb } from './helpers/testDb.js';
import { makeTeam, makeUser } from './helpers/factories.js';
import { LocalDiskStorage } from '../src/files/storage.js';
import { sweepOrphans } from '../src/files/repo.js';
import { files } from '../src/db/schema/index.js';

test('the orphan sweep removes only old, unattached files, from storage and from the table', async () => {
  const t = await createTestDb();
  const storage = new LocalDiskStorage(mkdtempSync(path.join(tmpdir(), 'sw-')));
  const N = await makeTeam(t.db, 'N');
  const u = await makeUser(t.db, { role: 'member', teamId: N.id });
  const now = new Date('2026-11-02T12:00:00Z');
  const hoursAgo = (h: number) => new Date(now.getTime() - h * 3600e3);
  async function addFile(key: string, createdAt: Date, attached: boolean) {
    const { size, sha256 } = await storage.put(key, Readable.from(['x']));
    const [row] = await t.db.insert(files).values({
      ownerId: u.id, teamId: N.id, storageKey: key, originalName: `${key}.png`, contentType: 'image/png', size, sha256, createdAt,
      ...(attached ? { attachedType: 'note', attachedId: '00000000-0000-4000-8000-000000000001' } : {}),
    }).returning();
    return row!;
  }
  const attachedOld = await addFile('aa0001', hoursAgo(48), true);   // old but attached: kept
  const fresh = await addFile('bb0002', hoursAgo(1), false);         // unattached but fresh (upload in progress): kept
  await addFile('cc0003', hoursAgo(25), false);                      // unattached and old: removed

  expect(await sweepOrphans(t.db, storage, hoursAgo(24))).toBe(1);

  const left = (await t.db.select({ id: files.id }).from(files)).map((r) => r.id).sort();
  expect(left).toEqual([attachedOld.id, fresh.id].sort());
  expect(await text(storage.get('aa0001'))).toBe('x');
  expect(await text(storage.get('bb0002'))).toBe('x');
  await expect(text(storage.get('cc0003'))).rejects.toThrow(/ENOENT/);
  await t.close();
});
```

- [ ] **Step 3: Implement the fixtures, `sniff.ts` and `storage.ts`**

- `make-fixtures.ts` writes:
  - JPEG: `FF D8 FF E0` followed by a minimal JFIF APP0 and `FF D9`;
  - PNG: the 8-byte signature plus IHDR/IDAT/IEND for a 1×1 image (zlib-deflate the scanline);
  - WebP: `RIFF????WEBPVP8 ` with a valid tiny VP8 chunk;
  - HEIC: an `ftyp` box with major brand `heic` plus a padding `mdat`;
  - PDF: `%PDF-1.4\n…%%EOF`;
  - `evil.svg`: `<svg xmlns="http://www.w3.org/2000/svg" onload="alert(1)"/>`;
  - `evil.html`: `<!doctype html><script>alert(1)</script>`.
- `sniff.ts` checks magic bytes on the first 32 bytes:
  - JPEG `FF D8 FF`;
  - PNG `89 50 4E 47 0D 0A 1A 0A`;
  - WebP `RIFF` at 0 and `WEBP` at 8;
  - HEIC `ftyp` at 4 with a brand in `heic|heix|hevc|hevx|mif1|msf1` at 8;
  - PDF `%PDF-` at 0.
- `storage.ts`, `LocalDiskStorage`:
  - keys must match `/^[a-f0-9]{6,64}$/`, otherwise it throws `invalid storage key`;
  - the path is `<root>/<key[0..2]>/<key>`;
  - `put` streams to `<path>.<rand>.tmp` while hashing, then `rename`s, and deletes the tmp on error;
  - `check()` writes and removes a probe file.

- [ ] **Step 4: Implement `routes.ts` and `repo.ts`**

- Register `@fastify/multipart` with `limits: { fileSize: config.uploadMaxBytes, files: 1, fields: 0 }`.
- The upload handler:
  1. reads the first chunk(s) until it has 32 bytes, then sniffs;
  2. for an empty or unknown file, drains the rest and throws;
  3. otherwise pipes the head plus the rest into `storage.put(randomBytes(16).toString('hex'), …)`;
  4. if the stream's `truncated` flag is set afterwards, deletes the stored object and throws `tooLarge()`.
- One transaction inserts the row and `audit('file.uploaded', { name, size, contentType })`. A download audits `file.downloaded`.
- `getVisibleFile` uses `visibleTo(actor, { owner: files.ownerId, team: files.teamId })`. Delete requires `canEdit`.
